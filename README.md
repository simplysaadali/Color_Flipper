# Color Flipper

A simple browser-based color flipper that changes the page background to a random hexadecimal color every 500 milliseconds.

## Features

- Start the automatic color-changing effect
- Stop and freeze the current background color
- Generates a new six-character hexadecimal color on every change
- No dependencies or build tools required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Controls

- **Start**: begins changing the background color
- **Stop**: stops the color-changing effect
